# Data and output dictionary

All output observations are generated by this repository's simulator. There is no
downloaded price dataset and no claim of observed market outcomes. Every cost uses
the normalized units defined in the model; no price scaling turns it into a return.

## Main study: `trials.csv`

One row is one strategy on one exogenous path. The key is `(trial, strategy)`.

| Column | Meaning |
|---|---|
| `trial`, `seed` | Replication index and independent exogenous-path RNG seed |
| `strategy` | One of the seven named policies in the README |
| `objective` | Population-weighted marked implementation shortfall plus inventory penalties |
| `shortfall` | Initial marked holdings minus final cash and terminal marked holdings |
| `temporary_cost` | Weighted sum of temporary quadratic execution cost |
| `drift_cost` | Negative post-trade inventory times true regime drift, integrated in time |
| `permanent_impact_cost` | Weighted post-trade inventory exposure to aggregate permanent impact |
| `noise_cost` | Realized cost from fundamental innovations; can have either sign |
| `inventory_penalty` | Weighted integrated quadratic post-trade inventory penalty |
| `terminal_penalty` | Weighted terminal residual-inventory penalty |
| `terminal_inventory_rms` | Square root of population-weighted squared final holdings |
| `integrated_inventory` | Population-weighted integrated squared post-trade inventory |
| `gross_turnover` | Population-weighted absolute signed traded inventory |
| `negative_rate_fraction` | Fraction of type/time cells that buy inventory back |
| `posterior_brier` | Auxiliary filter's mean squared positive-state probability error after the interval, including policies that ignore this filter |
| `filter_prior_brier` | Auxiliary filter's mean squared probability error before the interval; preserves the old generic prior diagnostic |
| `decision_brier` | Brier score of the planner's actual regime belief: zero for current-state informed; causal prior score for the three filter-driven policies; NaN for TWAP, AC-style, and drift-blind |
| `posterior_log_loss` | Auxiliary filter's mean negative log probability assigned to the true interval state |
| `accounting_error` | Maximum across types of absolute cash-ledger/decomposition discrepancy |

All strategies maintain a diagnostic filter. For `twap`, `ac`, `blind_mfg` and
`full_info_mfg`, these diagnostic beliefs do not determine the chosen actions;
filter-quality comparisons in the report use the three actual filter-driven policies.
The `NaN` decision scores for policies without state beliefs are intentional
unavailable values, not failed simulations. Auxiliary fields remain finite.

`summary.csv` contains trial-level means, standard errors, 95% Student-t intervals,
and sample counts. `objective_difference_vs_twap` forms paired differences before
summarizing. Time steps and heterogeneous types are not treated as independent trials.

## Equilibrium audit

`convergence_history.csv` stores every measured undamped relative residual by
coupling, damping and iteration. `convergence_summary.csv` adds the convergence
flag, final residual, final error against the direct solution, spectral radius of
the damped affine update and condition number of the direct equilibrium matrix.
A stable iteration can fail to meet a tight tolerance within a finite iteration cap;
a direct solution can exist even when a particular iteration is unstable.

## Finite-player audit

`finite_population.csv` contains one sampled population per row:

- `population_size`, `replicate`, `seed`: experiment identity.
- `mean_flow_rmse`: time-RMSE between actual finite mean flow and limiting flow.
- `terminal_impact_error`: signed difference in integrated permanent impact.
- `mean_deviation_gain`: average exact unilateral cost improvement across agents.
- `max_deviation_gain`: largest exact unilateral gain within that population.
- `sample_initial_inventory`: mean initial inventory in that finite population.

The report averages each of these values across population samples. In particular,
the average of within-sample maximum gains is not the maximum possible gain over
all populations or adaptive strategies.

## Sensitivity and example paths

`sensitivity.csv` records every impact/noise scenario, path, and policy. The grid is
prespecified. Paired differences share states and fundamental innovations within
each scenario. `example_paths.npz` contains named NumPy arrays for the single
prespecified illustration seed; array names are `{strategy}_{field}`. Prices and
inventories have `steps + 1` entries, while interval states, rates and beliefs have
`steps` entries. Posterior index t refers to state t after observing interval t.

`manifest.json` records configuration, seeds, sample sizes, versions, runtime,
source hashes and output hashes. Timestamps/runtime vary on rerun. The committed
CSVs round floats to twelve significant digits; array outputs preserve NumPy dtype
precision. The manifest itself is not included in its own hash map.

## Exact-completion supplement

`results/hard_liquidation/trials.csv` retains the same metric definitions for
512 additional paired paths and all seven policies. Every type has
`hard_liquidation=True` and `terminal_penalty=0`; all final inventories satisfy
the equality up to floating-point precision. Signed rates and intermediate short
positions remain allowed. Its `summary.csv` includes paired objective differences
against both TWAP and AC-style. These are separate model-conditional comparisons,
not a replacement for the default soft-terminal results.

The supplement's own manifest records its configuration, seed base, runtime,
maximum completion/accounting residuals, source hashes (including its experiment
script), and artifact hashes. The main study's `example_paths.npz` remains a
soft-terminal example. In that archive, `beliefs` and `posteriors` always refer to
the auxiliary filter, even for planners that do not use it.
